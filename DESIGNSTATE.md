## Product Direction (v3 — Claude DNA)
- **One-liner**: "Sift is your phone's quiet memory — a warm, private assistant that answers in plain words from the screenshots you actually saved."
- **Persona**: Maya, 31, PM who screenshots everything; one hand, 15–90s, at-the-moment-of-need sessions; aesthetics-sensitive; demands proof (every answer visibly grounded).
- **3 emotion keywords**: Warm (paper, terracotta, handled-not-clinical) / Essayist (recall is told in composed prose; serif is the signature) / Private (calm ownership: "Everything lives on this device." — no fear, no theater).
- **Voice guardrails**: sentence case everywhere; no exclamation marks; no emoji in UI; no "AI-powered/smart/magic" language; UI says "you", only assistant may say "I" sparingly; numbers in prose not badges.
- **Microcopy (binding)**: Ask empty headline "What would you like to remember?"; composer "Ask about anything you've saved…"; 4 example prompts (recipes / Lisbon flight / AirBnB Wi-Fi / deadlines & bills); typing "Looking through your screenshots…"; evidence line "Read from N screenshots" (singular "Read from 1 screenshot"); never answer without evidence — explicit "couldn't find that" + closest match instead; low-confidence labeled "partial match"; onboarding beats: "Your screenshots, remembered." / "Ask in plain words." / "Quietly private." with final CTA "Start sifting" landing on Settings' setup checklist (not Home); Settings header "Get Sift ready" 3-step checklist (Choose a provider / Add your API key / Enable auto-detect) with calm per-step copy; privacy lines per screen ("Your screenshots stay on this device." etc.).
- **Surviving product conclusions (unchanged)**: Library image-first + persistent Ask input; Chat = first-class tab; Detail image-first; Settings = setup checklist; evidence row = trust backbone; Home stats → one quiet sentence ("12 screenshots remembered"), never a dashboard.
- **Anti-goals**: no gradients/glass/glow/decorative shadows; no robot/sparkle/rocket/brain icons (asterisk-star mark only, Material rounded-outline icons); no AI-badge language; no cold blue-grey; no pure-black text; no per-provider colors; no stats wall; no ungrounded answers; no ALL-CAPS/letter-spaced labels; no emoji; don't regress fixed bugs (no fake Inter, watcher hoisted, real ThemeController, sanitized errors, backup disabled).

## Structure Plan (v3 — decided)
- **Navigation**: Claude-styled flat bottom nav, 3 tabs Library/Ask/More, NO floating capsule, NO shadow — edge-to-edge paper + hairline top only. Active = terracotta icon + ink label (color only, no indicator container, no badge/count). IndexedStack shell kept. No FAB. Capture = camera circle inside Library's pinned Ask bar. Actions History = Library header icon + a "Library" cluster row in More. No Ask input in More.
- **Global rhythm**: 4pt base, 20pt gutters, 32–48pt sections, 32pt chat turns; radius lock: cards 20, fields/buttons 16, thumbs 12, chips/pills full; nav bar radius 0. Serif = assistant voice (AI-written strings, summaries, chat answers, headlines); sans = all chrome. Tabular figures for dates/numerals; mono ONLY for OCR block.
- **Library**: pinned flat Ask bar (field + terracotta camera circle) → wordmark `Sift` + ONE quiet sentence (only stats surface) + pin/history icons → banners (flat) → time groups (Today/Yesterday/Earlier, small-caps sans, NO count badges) → 16:9 image-forward cards (image + time chip + pin toggle; serif 2-line summary; type badge + ≤3 tags) → empty states (serif headline) → 96pt bottom inset. Tablet ≥600pt 2-col grid, ≥1000pt 3-col.
- **Ask**: hero = serif headline + input + 4 example chips + Recent + privacy footnote. Conversation: user soft pill → **evidence strip ABOVE every answer** (48pt square thumbs r12 + "Read from N screenshots", N in terracotta tabular) → **assistant flat essay block** (serif, no container, left-aligned, full width, 32pt turn spacing) → flat typing row. Composer docked above nav (flat field + terracotta send). Tablet: conversation column centered max 680–720pt.
- **More**: single ListView, zero bordered cards. `More` headline → Library cluster (Actions history) → **"Get Sift ready" checklist** (1 Choose provider / 2 Add key / 3 Enable auto-detect; step numerals = status glyph, terracotta when done; progressive disclosure inline, no nested pages; YouTube key merges into step 2) → Appearance (segmented theme, quiet) → Behavior (haptics) → Privacy (local-only + 3 flat info rows + delete) → About (asterisk mark + version).
- **Onboarding**: 3 beats (Promise serif headline / Exchange with REAL chat components — user pill + evidence strip + serif essay line in a phone frame / Privacy + 3 flat trust rows), 3 quiet dots (active = terracotta), Skip top-right, final CTA "Set up Sift" → deep-links to More tab with checklist scrolled into view (shell must accept initial index + scroll target).
- **Detail**: hero sliver ~240pt full-bleed + back/pin/share quiet circles → type badge + status → **serif summary** → "What Sift sees" label + serif description (flat, no container) + recognition chips → extracted data rows (hairline) → Found online / Find online → Tags editor → OCR mono block (quiet, selectable) → Details rows. Action bar: pinned bottom paper bar on phone (primary FilledButton + Share); side rail ~260pt sticky at ≥840pt.
- **Actions History + Shopping**: quiet headers, de-containerized hairline rows, filter chips sentence case, empty serif state; Shopping = one quiet sentence progress ("2 of 5 items", NO %/bar), checkbox rows with line-through.
- **Do/don'ts**: one accent only; paper default; evidence strip mandatory above every answer; no stat walls; no card-soup; no gradients/glass/glow; no AI-badge language; sentence case; no exclamation/emoji; no FAB; no dividers between turns.
- **Build order**: 1) tokens+mark 2) shell+nav 3) conversation atoms (pill/strip/essay/typing) 4) Ask 5) Library 6) More 7) Detail 8) Onboarding 9) History+Shopping.
