## Product Direction (v2 — fresh)
- **Audience**: capture-heavy adults 22–38 (students, designers, PMs, travelers) with huge galleries; 15–90s one-handed sessions. Persona Maya, 28 product designer — judges on aesthetics, abandons template-made or evasive AI.
- **JTBD**: "When I remember I saved a screenshot, pull it up and act on it in seconds — without scrolling." Asking in plain words must be as fast as scrolling; every answer visibly grounded (replies show source screenshots).
- **Message/emotion**: "Your screenshots are a memory, not a junk drawer." 3 keyword feelings: **Lucid** (sharp type, airy spacing, decisive contrast), **Warmly intelligent** (capable friend, personable microcopy, organic accents, never clinical), **Reassuringly private** (your memory on your device, calm and contained).
- **Hierarchy**: Home hero = image-first screenshot cards + persistent Ask bar (stats = noise). Chat hero = conversation with grounded evidence (source thumbnails embedded in replies; empty state teaches recall with concrete example prompts). Detail hero = image + one-line summary; action second; "What SIFT sees" as second-read; OCR quiet + copyable. Settings hero = AI provider/key as a completion checklist, not a form dump. Onboarding hero = promise + **demo of recall** (show a "that flight from December?" → screenshot surfaces exchange).
- **Decisions**: (a) Chat = first-class tab (bottom nav, max 3: Library/Ask/More). (b) Onboarding 3 beats: promise → proof (recall demo) → trust+start (local-first privacy). (c) System/Light/Dark segmented, default System, dark = designed night mode.
- **Remove**: home stats row; per-card confidence badges; triple app-bar icons; gradient-tinted boxes; emoji in action names; monospace OCR styling (quiet, not mono).
- **Anti-goals**: startup-purple gradients, robot/sparkle motifs, neon/heavy glass, "AI-powered" badge language, dashboard/bento stats, card-soup pills, muted/archival beige, dark as afterthought, support-bot chat, hiding chat behind a header icon.

## Motion Plan (v2 — fresh)
- **Principles**: press feedback ≤80ms; every state change settles ≤400ms (ceiling 500 celebration). Springy-not-bouncy (easeOutCubic geometry; easeOutBack ONLY small amplitude on small elements, ≤1.06). Motion confirms state — no decoration. Reduced-motion: MaterialApp.builder checks disableAnimationsOf → zero durations, linear curves, stop loops, skip haptics.
- **Tokens**: press 60 / standard 200 / emphasis 300 / celebration 500. Curves: easeOutCubic for geometry; easeOutBack for the ONE overshoot (ember numeral count bump 300ms 1.08→1.0 on Home counts).
- **Micro**: nav tab = AnimatedSwitcher 200ms crossfade + color lerp to ember (no capsule/slide). Ask bar tap = instant tab swap + in-screen focus animation (AnimatedScale 0.98→1.0 180ms; never autofocus on mere tab switch). **Chip→conversation signature**: press 60ms; empty-state collapses AnimatedSize 280ms; conversation AnimatedSwitcher 250ms; user bubble AnimatedSlide offset 0.08→0 + opacity 200ms; total ≤1.2s. Card→Detail: PageRouteBuilder FadeTransition + SlideTransition Offset(0,0.04) 320ms easeOutCubic (no Hero). Source-thumbnail strip: one 300ms controller, per-index Interval stagger 40ms, 48px thumbs Fade+Scale 1.05→1.0. Send = AnimatedScale 0.92 60ms. Detail action bar rides the route (320ms); optional hide-on-scroll AnimatedSlide 200ms. Counts = TweenAnimationBuilder<int> 300ms.
- **Scroll**: card entrance one-shot fade+rise (translateY 24→0) 320ms easeOutCubic, stagger 60ms, cap 6 (never on scroll). Pinned Ask bar: NotificationListener → AnimatedContainer 180ms surface/elevation change at offset >4. Time-group headers static.
- **Loading**: skeleton = opacity pulse 0.55↔1.0 1200ms easeInOutSine (no gradient/sweep); typing = 3 dots opacity 0.4↔1.0, 600ms period, 120ms stagger, infinite until reply/reduced-motion; analyzing mark = 6% opacity pulse 1600ms (no rotation); processing banner in 200ms/out 150ms slide+fade; error banner slide −8→0 220ms.
- **Page-level**: onboarding PageView default slide + ember dots AnimatedContainer width 8→24 + opacity 200ms; mock exchange bubbles fade+rise 250ms, 80ms stagger (no type-out); sheet slide-up 250ms; dialog fade+scale 0.92→1.0 200ms; clear-chat → AnimatedSwitcher 250ms.
- **Haptics (sparse, reduced-motion-gated)**: scan capture mediumImpact once; send + chip lightImpact; action executed mediumImpact once. Never tab/scroll.
- **Forbidden**: Hero flights; scroll-triggered per-item anims; <2s spins; animating constraints in scroll hot paths (use transforms); idle loops; bounce on large elements; haptic spam; gradient shimmer.
